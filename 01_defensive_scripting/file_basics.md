To make a file:
Touch testing.txt - creates a text file
Echo test > testing.txt - assigns test into the testing.txt file
- note >> appends text
Cat testing.txt - prints what ever is in the file to the terminal

To remove a file:
rm testing.txt - removes the file name testing.txt
- note no bin in linux

mkdir test - creates a folder called test

ls - lists files in the directory
ls -l - provides more detail of what's in the folder
